# 2. Restricciones de Arquitectura

## 2.1 Restricciones técnicas
- **Backend**: Java con Spring Boot.
- **Base de datos**: PostgreSQL.
- **Frontend**: SPA (Single Page Application) con React.
- **Comunicación**: API REST entre frontend y backend, formato JSON.
- **Control de versiones**: Git/GitHub.

## 2.2 Restricciones organizacionales
- El desarrollo se realiza en equipo, con entregas por sprints/talleres definidos por la asignatura.
- La documentación de arquitectura se mantiene bajo el estándar arc42.

## 2.3 Convenciones
- Nomenclatura de código en inglés, nomenclatura de negocio en español.
- Diagramas siguiendo notación C4 (Contexto, Contenedores).
